UniReviews
Web app (source on GitHub) / Full-Stack developer, UI/UX designer — Flask (Python), JavaScript, HTML, CSS, Bootstrap
CONCEPT
This full-stack web application was designed to streamline the university selection process for prospective applicants, while also providing a transparent, peer-to-peer review platform for existing students. The system allows current students and alumni to submit detailed evaluations of their institutions, offering future applicants an authentic source of crowd-sourced information during the enrollment process. By offering a localized review infrastructure, the platform specifically assists Georgian students in selecting their desired university while promoting institutional accountability through transparent peer feedback.
SOURCE CODE ⛶ VIEW UNIREVIEWS ON GITHUB github.com/socialistmonkey/unireviews
TECHNICAL
Engineered using a full-stack architecture, the system utilizes Flask for backend routing and logic, while the frontend interface is built using HTML, CSS and JavaScript with the help of Bootstrap for a responsive layout. Data is handled via an SQLite database, implementing secure cryptographic processing to encrypt passwords and protect sensitive user data. The full source code is available on GitHub.
